# Recruitment Terminal

アークナイツの公開求人タグをもとに、有効なタグ組み合わせと候補オペレーターを確認できる検索ツールです。

就活用ポートフォリオとして、単なる一覧サイトではなく、タグ選択から候補確認までの体験と UI の見やすさを重視して制作しています。

## 公開 URL

https://recruitment-terminal.vercel.app/

## リポジトリ

https://github.com/Assy0562/recruitment-terminal

## 主な機能

- 公開求人タグの選択
- 選択タグから有効なタグ組み合わせ候補を表示
- 候補ごとのオペレーター一覧を表示
- オペレーターカードから詳細ページへ移動
- オペレーター画像、職業、配置、特性、素質、スキル情報の表示
- ダーク / ライトテーマ切り替え
- スマートフォンでも使いやすいレスポンシブ UI

## UI コンセプト

- アークナイツ風の SF・ミリタリー端末 UI
- ダークグレーを基調にした落ち着いた配色
- 控えめな境界線、グラデーション、ハーフトーン表現
- キャラクター画像が目立つ詳細画面
- 強いネオンや過度な装飾を避けた、シャープで見やすい画面

## 使用技術

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- ローカル JSON データ管理
- Vercel

## 開発

```bash
npm install
npm run dev
```

http://localhost:3000 を開いて確認できます。

## ビルド

```bash
npm run build
```
