## 検索用データ

既存153名のID、名前、レアリティ、職業、配置、特徴タグを、日本版ゲームデータの公開ミラーと比較した。検索タグは配置・職業・特徴タグに、レアリティに応じたロボット/初期/エリート/上級エリートを加える。職業タグの「タイプ」は既存UIに合わせ省略する。

参照先は [Kengxxiao/ArknightsGameData_YoStar](https://github.com/Kengxxiao/ArknightsGameData_YoStar/tree/57010cb5b2afea112cae57daa756b58676ba6850/ja_JP/gamedata/excel) の固定コミット `57010cb5b2afea112cae57daa756b58676ba6850`。

このミラーは取得時の最新コミットが2025-11-13であり、2026年の公開求人対象追加を反映していない。`gacha_table.json`だけを根拠に現在の対象を削除・追加しない。対象一覧は公式の日本版追加告知と現在の一覧で確認する。

## 今回追加した詳細データ

- 3名の基本情報・特性・素質は同コミットの `character_table.json`、スキルは `skill_table.json`、通常攻撃範囲は `range_table.json` に基づく。
- 素質は昇進2・潜在強化込みの最終候補、スキルは特化3、通常攻撃範囲は昇進2。モジュールによる変化は含めない。既存表示形式に合わせ装飾タグを除去し、スキルの変数を当該レベルの数値で置換した。
- 英語名はCarnelian/Kirara/Indigo。職分は既存の同職分データと同じ表記・アイコンを使用。
- 画像は既存と同じ [HellaAssets固定コミット](https://github.com/HellaOrg/HellaAssets/tree/2611135e7c018bec0f0fb72d94396e05a2609a58/operator) を使用。

既存153名の全スキル・素質説明の再検証、ゲーム内での表示照合は今回の対象外。確認日が新しいことは、全項目が最新仕様だと保証するものではない。
