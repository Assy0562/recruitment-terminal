# Recruitment Terminal

アークナイツの公開求人を参考にした、タグ組み合わせ検索ツールです。  
就活用ポートフォリオとして、既存サイトの丸コピーではなく、検索体験とUIの見やすさを自分なりに再設計しています。

## 公開URL

https://recruitment-terminal.vercel.app/

## リポジトリ

https://github.com/Assy0562/recruitment-terminal

## 主な機能

- 公開求人タグの選択
- 選択タグから有効なタグ組み合わせ候補を表示
- 候補ごとのスカウト可能オペレーター表示
- オペレーターカードから詳細ページへ遷移
- オペレーター画像、職業、配置、特性、素質、スキル情報の表示
- ダーク / ライトテーマ切り替え
- スマホでも使いやすいレスポンシブUI

## UIコンセプト

- アークナイツ風のSF・ミリタリー端末UI
- ダークグレーを基調にした落ち着いた配色
- 控えめな境界線、グラデーション、ハーフトーン表現
- キャラクター画像が最も目立つ詳細画面
- 強いネオンや過度な装飾を避けた、無骨でシャープな見た目

## 使用技術

- Next.js
- TypeScript
- Tailwind CSS
- App Router
- ローカルJSONデータ管理
- Vercel

## 開発

```bash
npm install
npm run dev
```

http://localhost:3000 を開いて確認できます。

## ビルド

```bash
npm run build
```
